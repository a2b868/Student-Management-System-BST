# Student Management System (BST Implementation)

## Overview
This is a Java-based application designed to manage student records efficiently using **Binary Search Trees (BST)** and **Priority Queues**.

## Features
- **Student Management:** Store name, ID, and grade.
- **Efficient Search:** Quick lookup using BST logic.
- **Priority Handling:** Manage students based on priority levels.
- **Traversal:** Display student lists using In-order traversal.

## Data Structures Used
- **Binary Search Tree (BST):** For core storage and searching.
- **Priority Queue:** Built on top of the BST structure.
- **Linked Structures:** Custom `Node` class for tree nodes.

## How to Run
1. Compile the files: `javac MainApp.java`
2. Run the application: `java MainApp`
